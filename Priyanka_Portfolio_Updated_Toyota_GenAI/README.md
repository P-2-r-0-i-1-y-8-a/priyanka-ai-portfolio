# Priyanka Gonugunta — Interactive Portfolio

A responsive, static personal portfolio built from Priyanka's supplied résumé and the personal AI learning projects discussed in the accompanying conversation.

## Quick start

Open `index.html` in your browser. No Python, API key, or build dependencies are required.

For a local web server, open a terminal in this folder and run:

```powershell
py -m http.server 8504
```

Then visit http://localhost:8504.

## Interactive features
- Dark/light theme switch
- Portfolio search (Ctrl+K on Windows or Cmd+K on Mac)
- Project category filters and detailed modal case studies
- Clickable skill categories
- Animated impact figures, scroll progress, and responsive layout
- Resume download, LinkedIn, email/contact controls

## Publish for free (GitHub Pages)
1. Create a **public GitHub repository** (for example, `priyanka-portfolio`).
2. Upload the **contents** of this folder to the repository root, keeping `assets/Priyanka_Gonugunta_Resume.pdf` in place.
3. In GitHub, select **Settings → Pages → Build and deployment → Deploy from a branch**.
4. Choose `main` and `/ (root)`, then Save.
5. After publication, GitHub gives you a URL similar to `https://YOUR-USERNAME.github.io/priyanka-portfolio/`.

No backend is required. This portfolio is a traditional static site (HTML/CSS/JavaScript), not a hosted AI chatbot. Project case studies describe actual résumé items and personal learning prototypes, without pretending confidential enterprise code is public.

## Before publishing
- Verify all résumé metrics and employment date ranges. The résumé describes Toyota's second role as "Nov 2025 – Till"; this portfolio uses a combined 2025–2026 display to avoid implying current employment.
- The copy uses the contact email and LinkedIn page from the résumé, which will become **public** if you publish the site.
- The current look uses CSS-only abstract artwork, so it works without a portrait photo or external assets. Google Fonts is optional; local fallback fonts work offline.
- Add GitHub/project demos only when URLs are available and you are comfortable sharing them.
